# 04-verify 验证段（待建）

嵌入式与硬件强耦合，无纯软件模拟，验证依赖工程师线下抓取的 artifact。

计划 skill：
- **`verify`**：可在机器上跑的部分——静态检查 + 单元测试。
- **`log-analyze`**：离线分析工程师抓取的报文 / 波形 / 日志。强制拷问：① log 放置方式 ② 各文件夹内容 ③ 分析 / 验证什么功能 ④ 找什么 bug ⑤ 反向出「抓取清单」（抓哪些信号、什么触发、什么采样率），工程师照单抓回后 agent 分析。
- **`hw-test`**：实机 / 硬件在环验证流程，引导工程师线下测并产出可分析 artifact。
